EE530 - GridLAB-D Project

1. Project Overview:

This project investigates the electrical demand of three residential houses supplied by a shared single-phase distribution transformer.

The project uses GridLAB-D to model household demand, electric water heaters, residential services, and transformer loading.

2. Project Objectives:

    - Model three residential houses.
    - Simulate household demand and water heating.
    - Compare four ZIP load models.
    - Analyze coincident demand.
    - Select and verify the appropriate distribution transformer.

3. Software Version:

    - GridLAB-D 5.3.0-20095
    - Git 2.50.1
    - Python 3.13.17

4. Repository Organization:

Project folders and files will be documented as development progresses.

5. Simulation Cases:

The project will include four ZIP load cases:

    i. Constant power.
    ii. Constant current.
    iii. Constant impedance.
    iv. Mixed ZIP model (40% impedance, 30% current, 30% power).

Simulation commands, dependencies, input datasets, and execution procedures will be documented after the models are developed and validated.
